\section{Reproducibility and Artifact Inventory}
The canonical primary packages provide source manifests, canonical tables, producer scripts, bootstrap settings, correction families, and generated figures for the within-phase Llama, Qwen, Gemma, and GPT-OSS analyses. The Llama Phase 2 Turbo package provides metric files and provenance manifests but is not marked strict-chain complete in the repository inventory. The causal-patching, calibration, adversarial, and prompt-filter additions have reports and selected metrics but are not strict-chain-complete packages.

The repository's claim-source registry maps every main-paper numerical claim to its canonical metric file and records whether the claim is primary, secondary, exploratory, or inconclusive. Percentages are formatted directly from canonical fields; fields already stored in percentage units are never multiplied by 100 again.

Known limitations include the absence of a matched random-vector control, incomplete full-context reconstruction for causal patching, model-specific decision semantics, reduced benign coverage in selected cells, and descriptive-only closed-model comparisons.
